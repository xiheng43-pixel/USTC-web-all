## 增删条目

`data.js` 里 `domestic` 是「正常访问」分区，`abroad` 是「国外网站」分区，各自按 `group` 分组：

```js
{
  name:  "MATLAB",
  emoji: "📈",                 // favicon 取不到时显示的兜底图标（必填，保证有图标）
  desc:  "信号与系统、自控、通信都用它",
  url:   "https://www.mathworks.cn/downloads/",   // 官方页，卡片上会显示
  tag:   "campus",             // free 免费 / campus 校内正版 / paid 需付费（数据保留，页面不再显示角标）
  kind:  "page",               // 可选：page 下载页 / direct 有直链；不写就是纯网址
  status:"unknown",            // ok 已验证 / unknown 未验证（数据保留，页面不再显示角标）
  direct:"https://...",        // 可选：直接开始下载的地址（显示「⚡ 直链」）
  icon:  "https://.../x.ico"   // 可选：自定义图标，不写就用 域名/favicon.ico
}
```

一个链接放哪个分区，就看国内网络能不能直接打开：能 → `domestic`，要国际网络 → `abroad`。

## 图标策略

1. 先用 `域名/favicon.ico`（可用 `icon` 覆盖）；
2. 加载失败或超时 → 自动换成条目里的 `emoji`；
3. 所以**每一张卡片一定有图标**，不依赖任何图标 CDN，断网也不会出现破图。

## 背景图与分类导航

- 背景：`html { background: url("bg.jpg") center top / cover fixed }` 铺满，上面盖 `body::before` 的一层淡色渐变（变量 `--veil-top / --veil-mid / --veil-end`，深色模式另有一组）。想更清楚就把三个 veil 的透明度调小，想更淡就调大。
- 分类导航：`#catnav` 由 `buildCatNav()` 按 `data.js` 的分组自动生成，点一下滚动到对应分组并高亮标题；分组标题前的大 emoji 来自分组对象的 `emoji` 字段。
- 换背景图：直接替换 `bg.jpg`，建议宽 1500–2000px、JPEG 质量 70–80（当前约 210KB）。

## 搜索

- 顶部小搜索框和首屏大搜索框同步；
- **打字时不过滤**：按下 Enter 或点放大镜才开始搜（避免边打字边缩范围）；`Esc` 清空并恢复全部；
- 匹配名称、描述、网址、分组名（搜「免费」「国外」「下载」也能命中）；
- 搜索时没有命中的分组和分类按钮会一起隐藏，清空后全部回来；
- `/` 聚焦搜索；
- 快捷标签：Python / MATLAB / 数电 / 深度学习 / 教务 / 免费（点了立即过滤）。

## 部署

四个文件纯静态、零依赖、无 CDN，直接传 GitHub Pages / Cloudflare Pages / Vercel，绑域名即可。

## 关于「已验证」

`status: ok` 是写作时联网确认服务器有响应；`status: unknown` 是自动抓取受限（多为境外站点反爬或超时）没能确认，**不代表打不开**，国内网络一般可直连。页面上分别显示 `✓ 已验证` 与 `? 未验证`。

只收录正规渠道，不涉及破解 / 盗版；真正要花钱的只有开发板一类硬件。
